# Flutter Notes App

A simple and user-friendly Notes App built using Flutter and Dart.

## Features

- View a list of notes with their titles, descriptions, and creation dates.
- Add new notes.
- Edit existing notes.
- Delete notes with a confirmation dialog.
- Form validation for required title and description fields.
- Empty state when no notes are available.

## Tech Stack

- Flutter
- Dart
- Material Design

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code or Android Studio

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd flutter-notes-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Note

Notes are stored in memory and may not persist after the application is restarted.
